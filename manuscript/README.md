# Manuscript workspace

This folder contains manuscript-facing materials for the UCEC methylation biomarker project.

## Files

- `manuscript_draft.md`: first full medRxiv-style manuscript draft.
- `preprint_v1.md`: cleaner preprint-style v1 with more formal framing, verified core references, and main results aligned to repository outputs.
- `references.bib`: BibTeX reference file for the preprint draft.
- `masters_application_abstract.md`: concise English research summary for graduate application materials.

## Notes

This is a computational and public-dataset-based biomarker discovery study. Before journal or preprint submission, please verify:

1. all references, DOIs, and dataset accession descriptions;
2. whether the intended wording should emphasize "detection" rather than "screening";
3. whether institutional review/ethics language is needed for public de-identified datasets;
4. whether all figures and tables cited in the manuscript exactly match the final exported files.
